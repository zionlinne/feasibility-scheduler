# Stage 1 冻结定义

## 核心定义（会议确认）

1. 任务图以 DAG 表示；依赖必须引用已存在的任务 ID。
2. 任务 ID 在同一张图内必须唯一。
3. 输出契约是任务完成可验收的必要字段。
4. 输入校验先于执行；非法图不得进入执行阶段。

## 补充定义

- 字段缺省与显式声明为空约束不同：`constraints_declared=false` 表示未提供，`true` 且约束集合为空表示明确声明为空。
- 空任务、缺失输出契约、缺失依赖、重复 ID、非法约束和环分别报告可区分错误。
- 固定任务图用于确定性测试，不代表真实业务规划结果。

## 暂缓事项

- 真实 API 调用、Worker 并发和重试策略。
- 时间窗、成本模型与三值可行性门禁的完整算法。
- 候选图拆分、合并及实验 A/B/C/D 的统计方案。

## 未核实事项

- 会议背景材料未提供可核对的具体消息，因此上述“会议确认”内容仅按当前任务验收标准落档，尚未独立核实。
